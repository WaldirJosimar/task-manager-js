# Task Manager (JavaScript)

Gestor de tareas sin frameworks: añade, completa, elimina y filtra tareas. Los datos se guardan en el navegador.

## Qué incluye
- Estado en memoria y renderizado dinámico del DOM
- Persistencia con `localStorage` (con manejo de errores)
- Filtros Todas / Pendientes / Hechas
- Consumo de una API pública con `fetch` y mensaje de respaldo si falla
- Accesibilidad: etiquetas, `aria-pressed` y foco visible

## Cómo usarlo
Abre `index.html` en el navegador. No necesita instalación.

## Tecnologías
HTML5 · CSS3 · JavaScript (ES2022)
